# Placement

Placement服务主要用于跟踪服务资源的使用情况，即动态资源监控

## Placement概述

在OpenStack中包括计算、存储、网络等资源，Placement用于跟踪管理每种资源当前的使用情况。早期的OpenStack架构中是没有Placement服务的，Placement服务在OpenStack 14.0.0 Newton版本中被引入到nova库，并在19.0.0 Stein版本中被独立到Placement库，即在Stein版本被独立成模块

Placement服务使Project能够跟踪自己的资源，Project可以通过Placement HTTP API将自己的资源注册到Placement服务或从Placement服务中删除自己的资源。Placement服务提供REST API堆栈和数据模型，用于跟踪*资源提供者*不同类型的资源的库存和使用情况，资源提供者可以是计算资源、共享存储池、IP池等。例如，创建一个实例会消耗计算节点的CPU、内存，会消耗存储节点的空间，会消耗网络节点的IP等，所消耗资源的类型被跟踪为*类*，Placement提供了一组标准资源类，例如DISK_GB、MEMORY_MB、VCPU，也可以根据实际需求自定义资源类

Placement组件服务提供了placement-api，一个标准的WSGI脚本，用于使用Apache、nginx或其他支持WSGI的Web服务器运行服务，因此Placement服务托管在httpd上，修改配置后需重启httpd。placement-api作为标准的WSGI脚本，提供模块级别application属性，这意味着可以在许多不同的服务器上运行它。通过placement-api接口可以实现跟踪project里的资源，然后将跟踪的资源同步到数据库，因此Placement组件本身并不复杂，仅仅是提供了动态资源监控的功能

## Placement部署

### 一、先决条件

1. 数据库配置

   ```bash
   # 1.登录MariaDB
   [root@controller ~]# mysql -uroot -predhat
   
   # 2.创建名为placement的数据库
   MariaDB [(none)]> CREATE DATABASE placement;
   
   # 3.创建placement账户并授权
   MariaDB [(none)]> GRANT ALL PRIVILEGES ON placement.* TO 'placement'@'localhost' IDENTIFIED BY 'openstack_placement';
   MariaDB [(none)]> GRANT ALL PRIVILEGES ON placement.* TO 'placement'@'%' IDENTIFIED BY 'openstack_placement';
   MariaDB [(none)]> FLUSH PRIVILEGES;
   ```

2. 创建Placement服务凭证

   ```bash
   [root@controller ~]# source admin-openrc
   [root@controller ~]# openstack user create --domain default --password openstack_placement placement
   [root@controller ~]# openstack role add --project service --user placement admin    # 关联Project与Role
   [root@controller ~]# openstack service create --name placement --description "Placement API" placement    # 创建placement服务实体
   [root@controller ~]# openstack service list
   ```

3. 为服务实体创建API EndPoint

   ```bash
   [root@controller ~]# openstack endpoint create --region RegionOne placement public http://controller:8778
   [root@controller ~]# openstack endpoint create --region RegionOne placement internal http://controller:8778
   [root@controller ~]# openstack endpoint create --region RegionOne placement admin http://controller:8778
   ```


### 二、安装配置

1. 安装Placement

   ```bash
   [root@controller ~]# yum install -y openstack-placement-api
   ```

2. 修改Placement配置文件，连接数据库

   ```bash
   [root@controller ~]# cp /etc/placement/placement.conf{,.bak}
   [root@controller ~]# grep -Ev "^$|^#" /etc/placement/placement.conf.bak > /etc/placement/placement.conf
   [root@controller ~]# chown root.placement /etc/placement/placement.conf.bak
   
   [root@controller ~]# vim /etc/placement/placement.conf
   [api]
   auth_strategy = keystone    # 认证策略，指定api接口的认证方式，通过keystone认证
   
   [keystone_authtoken]
   auth_url = http://controller:5000/v3
   memcached_servers = controller:11211
   auth_type = password
   project_domain_name = default
   user_domain_name = default
   project_name = service
   username = placement
   password = openstack_placement
   
   [placement_database]
   connection = mysql+pymysql://placement:openstack_placement@controller/placement
   ```

3. 同步Placement服务的初始数据到Placement库

   ```bash
   [root@controller ~]# su -s /bin/sh -c "placement-manage db sync" placement
   /usr/lib/python2.7/site-packages/pymysql/cursors.py:170: Warning: (1280, u"Name 'alembic_version_pkc' ignored for PRIMARY key.")
     result = self._query(query)
   [root@controller ~]# mysql -uroot -predhat placement
   MariaDB [placement]> SHOW TABLES;    # 验证placement的表是否正常
   ```

   初始化placement数据库时可能会产生一个Warning告警，声明placement数据库中存在一个会被忽略的主键`alembic_version_pkc`，忽略此告警即可

4. 修改httpd服务

   在OpenStack的Rocky版本种有单独对于Placement API组件服务的说明，由于OpenStack的打包错误，您必须通过将以下配置添加到/etc/httpd/conf . d/00-nova-Placement-API . conf来启用对Placement API的访问

   ```bash
   [root@controller ~]# vim /etc/httpd/conf.d/00-placement-api.conf
   <VirtualHost *:8778>
   ...
     Errorlog /var/log/placement/placement-api.log
     <Directory /usr/bin>    # 此配置需要手动添加，缺省情况下Placement没有这一段配置
       <IfVersion >= 2.4>
         Require all granted
       </IfVersion>
       <IfVersion < 2.4>
         Order allow,deny
         Allow from all
       </IfVersion>
     </Directory>
   </VirtualHost>
   [root@controller ~]# systemctl restart httpd
   [root@controller ~]# systemctl enable httpd
   ```

   此处的HTTP配置文件无论是否修改，似乎不会影响到Placement组件服务本身，但是配置到Nova组件服务时会需要配置Placement相关的内容，即Nova组件服务会有需要调用Placement组件的API服务，如果没有手动修改Placement组件服务的HTTP服务配置，那么Nova组件请求Placement组件API服务时会被拒绝，可查看`/var/log/placement/placement-api.log`错误日志：`AH01630: client denied by server configuration: /usr/bin/placement-api`

### 三、验证

1. 安装osc-placement插件

   Placement服务状态需要通过osc-placement插件检查，osc-placement插件需要通过pip安装，CentOS默认的Base源中没有pip软件包，需要通过扩展源EPEL安装。使用pip安装osc-placement插件时需要使用阿里云镜像源安装插件，缺省的源可能会因为无法验证服务器的SSL证书而导致安装失败

   ```bash
   yum install -y python-pip
   [root@controller osc-placement]# pip install osc-placement==2.2.0 --index-url https://mirrors.aliyun.com/pypi/simple/
   ```

   在安装osc-placement插件的步骤上需要比较注意，首先使用YUM安装的软件包是`python-pip`而不是`pip`，其次使用pip安装osc-placement插件时一定要指定2.2.0版本号，以上两点任一一点错误都有可能导致使用osc-placement插件验证时出现错误，无法正常获取到验证结果。使用阿里云镜像源安装插件是因为缺省的源可能会因为无法验证服务器的SSL证书而导致安装osc-placement插件失败

   Placement组件服务本身并不像其他组件服务一样提供某一个具体的功能，例如Nova组件提供计算虚拟化功能、Neutron提供网络虚拟化功能，Placement仅用于动态资源监控

2. Placement状态检查

   ```bash
   [root@controller ~]# placement-status upgrade check
   
   # 列出可用的资源类和特征
   [root@controller ~]# openstack --os-placement-api-version 1.2 resource class list --sort-column name
   +----------------------------+
   | name                       |
   +----------------------------+
   | DISK_GB                    |
   | FPGA                       |
   |...                         |
   [root@controller ~]# openstack --os-placement-api-version 1.6 trait list --sort-column name
   +---------------------------------------+
   | name                                  |
   +---------------------------------------+
   | COMPUTE_DEVICE_TAGGING                |
   | COMPUTE_GRAPHICS_MODEL_CIRRUS         |
   | ...                                   |
   ```
   
   列出资源类成功就表示Placement安装成功。在安装pip工具时，python-pip工具本身属于epel源，本地yum同步过epel源，所以python-pip工具的安装没有问题，但是osc-placement工具是需要使用pip工具安装，如果controller节点能通外网，安装没有问题，如果controller节点不通外网，可以在yum01节点上使用`pip download osc-placement==2.20`命令将离线包下载到本地，再将离线版传输到controller节点，controller节点使用`pip install osc-placement-2.2.0.tar.gz`本地安装
